## 🛠️ Windows 10 & 11 Extension Security Fix (Chrome & Edge)

If you encountered any of these Windows 10 / Windows 11 browser security errors:
1. **Windows 10 / 11 Chrome & Edge Security Block:** Dragging `.crx` adds the extension, **but the toggle switch is greyed out / cannot be turned ON** (*"This extension is not listed in the Chrome Web Store"*).
2. **Microsoft Edge Error:** `Package is invalid: 'CRX_REQUIRED_PROOF_MISSING'`

### 🟢 Why This Happens & How to Fix It Permanently in 5 Seconds
On Windows 10 & Windows 11, Google Chrome and Microsoft Edge enforce an OS policy that **disables raw `.crx` files** installed outside the official Web Store — even when Developer mode is ON.  
However, **loading the extracted FOLDER ("Unpacked") is 100% allowed on every Windows 10 & 11 PC and turns the switch ON permanently!**

#### Method 1: Drag & Drop the Unpacked Folder / "Load unpacked" (Fastest — 100% Works)
1. Download & Extract **`DuoVista-PDF-Studio-v2.1.0-Unpacked.zip`** (or use this repository folder).
2. Open Chrome (`chrome://extensions`) or Edge (`edge://extensions`).
3. If there is a greyed-out/disabled DuoVista card from an old `.crx` drop, click **Remove** on it.
4. Turn **ON** **"Developer mode"** (top-right in Chrome, bottom-left in Edge).
5. Click **"Load unpacked"** and select the extracted `DuoVista-PDF-Studio` folder *(or simply drag & drop the **extracted folder** directly onto the extensions page!)*.
6. **Done!** The toggle switch turns **ON immediately** with zero warnings!
7. *(Optional)* Click **"Details"** and turn **ON** **"Allow access to file URLs"** so local PDFs open directly.

#### Method 2: 1-Click Windows 10/11 Auto-Fixer (`Fix-Windows-10-11-Extension.bat`)
1. Double-click **`Fix-Windows-10-11-Extension.bat`** (click **Yes** if UAC prompts).
2. It automatically unlocks Windows Registry (`HKLM` & `HKCU` `ExtensionInstallAllowlist` + `ExtensionInstallSources`), extracts/installs the clean folder (`C:\DuoVista-PDF-Studio` or `%LOCALAPPDATA%\DuoVista-PDF-Studio`), highlights it in Explorer, copies the path, and opens Chrome/Edge Extensions!
3. Simply drag the highlighted folder onto `chrome://extensions` or `edge://extensions` (with Developer mode ON) or click **Load unpacked** -> `Ctrl+V`!

## 🌟 Key Features of DuoVista PDF Studio

1. **⬒ Ultra-Thin 2px Hairline Divider:** Up-Down (Top & Bottom) default split + Side-by-Side + Single mode, with zero bulky middle toolbars. Double-click or double-tap to reset to 50:50.
2. **📑 1 PDF or 2 Different PDFs Mode:** Read passage on top & questions below in 1 PDF, OR compare 2 completely different PDFs simultaneously.
3. **✏️ Microsoft Edge-Style Annotations:** Highlighter (4 colors), Freehand Pen (4 colors), Movable Text Notes, Eraser, and Clear Page.
4. **🧹 Clean Distraction-Free Reading Header:** Unnecessary welcome buttons hide cleanly when reading, placing themes, audio player, timer presets, and app/developer info inside the **3-Line Slide Menu (`☰`)**.
5. **🎧 Built-in IELTS & Exam Companion (`IELTS Sheet`):** 20/30/60-min Timer & Stopwatch, MP3 Listening Player, Q1–40 auto-saved Answer Sheet with `.TXT` export, and Scratchpad.
