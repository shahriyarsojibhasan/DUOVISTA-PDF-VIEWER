## 🚀 How to Install in Chrome or Edge (30 Seconds)

1. Open **Google Chrome** (`chrome://extensions`) or **Microsoft Edge** (`edge://extensions`).
2. Turn ON **"Developer mode"** in the top-right corner.
3. Click **"Load unpacked"** in the top-left corner.
4. Select this directory:
   `c:\Users\Shahr\OneDrive\Desktop\dual mode pdf viewer`
5. Click **"Details"** on **DuoVista PDF** and turn ON **"Allow access to file URLs"**.
6. Pin DuoVista PDF to your toolbar!
