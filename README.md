## 🛠️ Solutions for Chrome & Edge Installation Warnings

If you encountered errors when installing:
1. **Microsoft Edge Error:** `Package is invalid: 'CRX_REQUIRED_PROOF_MISSING'`
2. **Google Chrome Error:** `This extension is not listed in the Chrome Web Store and may have been added without your knowledge` (switch toggle greyed out)

Here are the **two instant, 100% working solutions**:

---

### 🟢 Method 1: Load Unpacked (Recommended — 100% Guaranteed & Easiest)
Chromium (Google Chrome & Microsoft Edge) allows all developer extensions permanently when loaded unpacked without ANY store proof check or warning:

#### For Google Chrome:
1. Download & Extract **`DuoVista-PDF-Studio-v2.1.0-Unpacked.zip`** (or use this repository folder).
2. Open Chrome and navigate to: `chrome://extensions`
3. Turn **ON** the **"Developer mode"** toggle switch in the **top-right corner**.
4. Click the **"Load unpacked"** button in the **top-left corner**.
5. Select the `DuoVista-PDF-Studio` folder (or `dual mode pdf viewer` folder).
6. **Done!** The extension is immediately active and permanently enabled with zero warnings.
7. *(Optional)* Click **"Details"** on DuoVista and turn **ON** **"Allow access to file URLs"** so local PDFs open directly.

#### For Microsoft Edge:
1. Download & Extract **`DuoVista-PDF-Studio-v2.1.0-Unpacked.zip`** (or use this repository folder).
2. Open Microsoft Edge and navigate to: `edge://extensions`
3. Turn **ON** the **"Developer mode"** toggle switch in the **bottom-left sidebar**. *(In Edge, this must be switched ON to bypass proof checks)*.
4. Click the **"Load unpacked"** button in the top bar.
5. Select the `DuoVista-PDF-Studio` folder.
6. **Done!** DuoVista will load cleanly with NO `CRX_REQUIRED_PROOF_MISSING` error.

---

### 🔵 Method 2: Sideloading CRX with 1-Click Windows Allowlist Fix
If you prefer dragging and dropping the `.crx` file (`DuoVista-PDF-Studio-v2.1.0.crx`):

1. Double-click the included script **`Enable-DuoVista-Allowlist.bat`** (or double-click **`Enable-DuoVista-Allowlist.reg`**).
2. This automatically adds DuoVista's extension ID (`nddnddpjpbnkkbekjdflejaefbeniloa`) into the trusted Enterprise Allowlist for **Google Chrome**, **Microsoft Edge**, and **Brave**.
3. Now:
   - On **Chrome**: The greyed-out toggle switch becomes **enabled** and the "not listed in store" block disappears.
   - On **Edge**: Make sure **"Developer mode"** is toggled ON at the bottom-left of `edge://extensions`, then drag & drop the `.crx` file. It installs smoothly without proof errors!

## 🌟 Key Features of DuoVista PDF Studio

### 1. 🧹 Clean, Distraction-Free Reading Toolbar
- When any PDF is opened, extra clutter buttons (like "Sample PDF") automatically disappear to give you total reading focus.
- The **Sample IELTS Test** is available on the welcome home screen or anytime via the 3-line slide drawer menu (`☰`).
- Modern floating micro-controls for page navigation and zoom in each pane.

### 2. ☰ 3-Line Slide-Out Menu Drawer (Hamburger Menu)
All secondary tools are neatly organized:
- **☕ Cheer Up & Support / Buy Me a Coffee**: Direct link to cheer up developer Shahriyar Sojib Hasan (`buymeacoffee.com/shahriyarsojibhasan`).
- **👨‍💻 App & Developer Info**: Version `v2.1.0`, creator bio, and dedication to global students.
- **🎨 One-Click Reading Themes**: Quick chips for ☀️ Light, 🌙 Dark, and 📜 Sepia (Eye-Care).
- **🎧 Listening Audio Player**: Play and seek MP3 audio tracks directly from the drawer while reading or taking mock tests.
- **⚡ Quick Actions**: Swap Panes (Top ↔ Bottom), 50:50 Reset, and Toggle Synchronized Scrolling.
- **⌨️ Keyboard Shortcuts Reference**: Fullscreen (`F11`), double-click divider reset, and hover scroll.

### 3. ⬒ Ultra-Thin 2px Hairline Divider
- Clean 2px divider between Top and Bottom panes.
- Drag up or down smoothly to adjust split ratio.
- Double-click the hairline divider to reset to exact 50:50.

### 4. 📑 2 Different PDFs Mode
- View **two completely different PDF files** simultaneously:
  - Top: Reading Passage or Question Paper.
  - Bottom: Answer Sheet, Notes, or Solutions.

### 5. ✏️ Microsoft Edge-Style Annotations
- Built-in Text Highlighter (4 colors), Freehand Digital Pen, Add Text Notes, and Eraser.
